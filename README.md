# 📆 Problem Solving

알고리즘 문제 플랫폼(백준, 프로그래머스, 정올 등)에서 푼 문제의 풀이 코드를 모은 저장소예요.

**지속 가능한 성장**과 **명료한 코드 작성**을 목표로 꾸준히 문제를 풀고 있어요.

```text
problem-solving/
├── Algorithm/              # 주제별 알고리즘 구현
│   └── Data Structure | Graph | String | …
├── Baekjoon Online Judge/  # 백준 난이도별 풀이
│   └── bronze | silver | gold | platinum | diamond | unrated
├── HackerRank/             # SQL 주제별 풀이
│   └── Basic Select | Aggregation
├── Programmers/            # 문제 모음별 풀이
│   └── Coding Test High Score Kit | SQL High Score Kit | PCCE | …
├── SW Expert Academy/      # 난이도별 풀이
│   └── D1 ~ D4
├── Jungol/                 # 정올 문제 풀이
│   └── Intermediate
├── Algospot/               # 알고스팟 문제 풀이
├── Codetree/              # 코드트리 Trail별 풀이
├── goorm/                  # 구름 문제 풀이
├── LeetCode/               # LeetCode SQL 풀이
└── templates/              # 풀이 템플릿
    └── Main.java | Main.py
```

## 풀이 해설

풀이 과정과 해설은 [블로그](https://kyr-db.tistory.com/)에 정리하고 있어요.

## 커밋 규칙

커밋 메시지는 다음 형식을 지향해요.

```text
<플랫폼>: <유형> <문제 번호> <문제명> [언어]
```

문제 번호는 있는 경우에만 적어요. 새 풀이를 추가할 때는 다음과 같이 작성해요.

- `boj: solve 1000 A+B [java]`
- `programmers: solve 택배 상자 꺼내기 [python]`
